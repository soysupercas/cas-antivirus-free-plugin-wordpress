== Description ==

Lightweight Security. Powerful Protection.

CAS Antivirus Free is a lightweight yet powerful security plugin designed to protect WordPress websites through an intuitive, modern and easy-to-use interface.

Whether you manage a personal blog, a business website or an online store, CAS Antivirus Free helps defend your WordPress installation against common security threats without compromising performance. It is suitable for both beginners and advanced users looking for reliable protection with minimal configuration.

Unlike many free security plugins, CAS Antivirus Free includes a powerful malware scanner with WordPress core integrity verification and automatic core restoration. Modified core files can be detected and restored safely using the official WordPress core.

The plugin also provides six essential HTTP Security Headers to improve browser-level security together with Two-Factor Authentication (TOTP) to protect administrator accounts from unauthorized access. All QR codes are generated locally, ensuring authentication data never depends on third-party services.

== Installation ==

1. Upload the plugin to the `/wp-content/plugins/` directory.
2. Activate the plugin from the WordPress Plugins page.
3. Open **Cas Antivirus Gratuito** from the WordPress administration menu.
4. Configure the desired security options.

== Frequently Asked Questions ==

= Does it work with any WordPress theme? =

Yes. CAS Antivirus works independently of the active theme.

= Is Two-Factor Authentication included? =

Yes. The plugin supports any TOTP compatible application such as Google Authenticator, Microsoft Authenticator, Authy and similar apps.

= Does it modify WordPress core files? =

No. CAS Antivirus uses WordPress hooks and APIs without modifying WordPress core files.

= Does it require an external service to generate QR codes? =

No. QR codes are generated locally by the plugin.
