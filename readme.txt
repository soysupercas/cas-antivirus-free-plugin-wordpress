== Description ==

CAS Antivirus is an all-in-one security plugin designed to improve the protection of WordPress websites through an intuitive interface suitable for both beginners and advanced users.

Free features include:

* Layered security protection.
* HTTP Security Headers.
* Login URL protection.
* Two-Factor Authentication (TOTP).
* Custom 404 page.
* Login activity monitoring.
* Failed login log.
* Security event logging.
* Simple and intuitive administration panel.

Professional features include:

* Advanced firewall.
* Additional hardening shields.
* Advanced attack protection.
* Extra monitoring tools.
* Additional security modules.

The free version provides essential protection while the Pro version unlocks advanced security capabilities for users who require a higher level of protection.

== Installation ==

1. Upload the plugin to the `/wp-content/plugins/` directory.
2. Activate the plugin from the WordPress Plugins page.
3. Open **CAS Antivirus** from the WordPress administration menu.
4. Configure the desired security options.

== Frequently Asked Questions ==

= Does it work with any WordPress theme? =

Yes. CAS Antivirus works independently of the active theme.

= Is Two-Factor Authentication included? =

Yes. The plugin supports any TOTP compatible application such as Google Authenticator, Microsoft Authenticator, Authy and similar apps.

= Does it modify WordPress core files? =

No. CAS Antivirus uses WordPress hooks and APIs without modifying WordPress core files.

= Does it require an external service to generate QR codes? =

No. QR codes are generated locally by the plugin.
